# Web Art

A starter website for Web Art, a digital agency and digital products marketplace.

## Run locally

1. Install Node.js (LTS).
2. In this project folder, run `npm install`.
3. Run `npm run dev`.
4. Open http://localhost:3000.

## Deploy

Import this GitHub repository into Vercel. Framework preset: Next.js. Build command and output settings can remain at their defaults.

This is the initial frontend only. Checkout, authentication, admin tools, product delivery, and payment integrations will be added in later steps. Do not list products unless you have the rights to distribute them.
